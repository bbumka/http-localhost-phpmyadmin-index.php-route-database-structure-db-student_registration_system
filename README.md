学校管理システム (School Management System)
このプロジェクトは、学校の運営を効率化し、学生の登録およびデータベース管理を行うためのWebベースのシステムです。
主な機能
￼ 学生登録: 新規学生の追加、登録情報の更新、削除が可能です。
￼ データベース管理: 学生の情報をMySQLデータベースに安全に保存します。
￼ ユーザーインターフェース: 直感的で使いやすいデザインを採用しています。
使用技術
￼ フロントエンド: HTML, CSS, JavaScript
￼ バックエンド: PHP
￼ データベース: MySQL
セットアップ方法
1 リポジトリのクローン:
⁠git clone [https://github.com/ユーザー名/school-management-system.git](https://github.com/ユーザー名/school-management-system.git)⁠
2 サーバーの設定:
￼ XAMPPまたはWAMPサーバーを起動します。
￼ プロジェクトファイルを ⁠htdocs⁠ フォルダに配置します。
3 データベースの設定:
￼ ⁠phpMyAdmin⁠ にアクセスし、新しいデータベースを作成します。
￼ プロジェクトに同梱されている ⁠.sql⁠ ファイルをインポートしてください。
4 実行方法:
￼ ブラウザで ⁠http://localhost/school-management-system⁠ にアクセスして実行します。
